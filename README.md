# Galaxy Adaptive Bar

Galaxyのステータスバーを、背景に合わせて読みやすくするVectorモジュールです。文字ごと・パーツごと・背景に合わせる自動モードで配色し、通常のステータスバー表示へ戻すこともできます。

## 主な機能

- 「配色する単位」で文字ごと／パーツごと／自動を選択。パーツごとは日付と時刻をそれぞれ1色に揃え、同じ表示欄でも別々に判定します。自動ではパーツ単位で読みやすさを保ち、文字ごとの方が読みやすくなる部分だけ切り替えます。背景が落ち着いてからパーツへ戻し、地図や写真の移動中に切り替わりを繰り返すことを抑えます。初期値は従来の文字ごとで、設定変更はそのまま反映されます。
- 白黒の自動配色、フェード時間・更新頻度・判定方法の調整。
- One UIホームのアプリ開閉・履歴への追従。途中でジェスチャーを戻す操作にも追従。
- 時計・通知・通信表示・バッテリーの配色を個別に切り替え。
- 通知が収まりきらないときの点も、通知アイコンと同じ設定で背景に合わせて配色。
- Android 17の通信速度表示の配色と、数値・単位の行間調整。
- Android 17でカメラ・マイクの使用表示に合わせて右側のアイコンを移動。純正の変形を保ちながら丸い緑の点を少し大きく表示し、空き不足時に純正へ戻す設定。使用表示から緑の点への切り替えでも、右側アイコンを滑らかに移動します。
- 消灯・ロック中のキャプチャ停止、個別のクラッシュ保護、起動後の自動復帰。
- Material 3の設定画面と、検索可能なライセンス一覧。

## 対応環境

実機確認の対象はGalaxy S26 Ultra（SM-S948Q）のAndroid 16 / One UI 8.5（AZHL）とAndroid 17 / One UI 9（BZI9）です。両バージョンの処理を分けて維持しています。対応するroot環境とlibxposed API 102対応Vectorが必要です。別の端末・ファームウェア・ホームのバージョンでは、未確認の処理を適用しません。

## 導入・更新

1. [Releases](https://github.com/OneUI-Mods/galaxy-adaptive-statusbar/releases)から署名済みrelease APKをインストールします。同じパッケージの更新は上書きし、設定を保持します。
2. Vectorでモジュールを有効にし、SystemUIとOne UIホームを対象に選びます。
3. 初回導入・APK更新後は対象プロセスを再読み込みします。SystemUIには[Galaxy Reload](https://github.com/OneUI-Mods/galaxy-reload)も利用できます。再読み込み方法によってはロック解除が必要です。
4. アプリで自動配色と必要な機能をONにします。通常の設定変更ではプロセスの再読み込みは不要です。

## 制限・停止

縦画面・単一ディスプレイを中心に確認しています。横画面、分割画面、DeX、すべてのHome Up効果の動作を保証するものではありません。パーツモードで区切りを認識できない時計書式は、表示全体を1パーツとして扱います。保護画面や背景を判定できない場面では純正色へ戻します。背景画像の保存は診断用設定を明示的にONにした場合に限ります。

機能を止める場合はアプリのスイッチをOFFにします。完全に外す場合はVectorで無効にして対象プロセスを再読み込みしてください。異常終了を繰り返すと対象ごとの保護が働きます。原因を解消してからアプリで保護を解除します。

### 充電中の表示（Android 17）

「調整」タブの「充電演出中もステータスバーを表示」をONにすると、純正の充電アニメーションを保ちながら時計・通知・通信状態を表示します。拡大した電池表示に合わせて隣接アイコンが左へ移動し、縮小すると元へ戻ります。通常の電池へ戻るときも、位置と大きさを合わせて滑らかにフェードし、残量表示を受け渡します。初期値はONで、設定変更は次の充電アニメーションから適用します。

## 文字列の互換性

文字ごとの配色判定と保存データの読み取りで、一部の空白文字や空の文字列を従来どおりに扱うよう修正しました。

## 更新後の互換性確認

対象アプリの更新後は、このアプリを一度開いて準備を完了してから、対象アプリを開き直してください。探索結果は各アプリ内に保存し、変更がなければ再探索しません。他のOneUI Modsアプリを入れる必要はありません。対応先を一意に確認できない機能は適用を止めます。OSやアプリのすべての更新への対応を保証するものではありません。

# Android 16の互換性記録

- 基準ソース: `556f51e725c23c258d64db6fe7bd53d316087bdb`
- 対象: Android 16 / API 36。従来の端末・ユーザー・構造検証の条件を維持します。
- `Android16Hooks`へ元のOS判定を分離しました。フック本体の実装は変更していません。
- 元の自作ソースのSHA-256を`android16-source.json`へ保存しています。後の17向け変更と区別し、Gitの基準コミットから完全な16向け実装を再現できます。
- 共通の計算・UI処理は共有し、17で契約が変わったフックだけを17向け実装へ分けます。17の判定が失敗しても16のプロファイルにはフォールバックしません。

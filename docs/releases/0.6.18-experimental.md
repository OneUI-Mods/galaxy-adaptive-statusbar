# カメラ起動時の表示とSystemUIの再読み込みに対応

Samsungカメラなどが全画面を要求している間は、使用表示に合わせた移動処理が右側のアイコンを表示し直さないようにしました。大きな使用表示が出る前に、小さな点の余白だけが先に動く挙動も抑えています。

別アプリ「Galaxy Reload」と組み合わせると、解除済みの画面状態を引き継いでSystemUIを再読み込みできます。GUIとrootコマンドから利用でき、再読み込み前に画面がON・解除済みであることを確認します。消灯や強制認証が発生した場合、引き継ぎは中止します。認証設定は変更しません。

カメラ・マイク表示の移動と点の拡大は「調整」でONにしてください。空き不足時に純正へ戻す設定もON/OFFできます。対応外の画面では純正表示を維持します。

Galaxy S26 Ultra（SM-S948Q）のAndroid 16 / AZHL、Android 17 / BZI9向け。使用表示の移動はAndroid 17の縦画面・左から右へ読むレイアウト向けです。rootとAPI 102対応Vectorが必要です。Android 16の既存機能は維持しています。

署名済みrelease APKを上書きしてください。新しい再読み込み機能を使うにはGalaxy Reloadの対応版も必要です。初回の読み込みや引き継ぎに失敗した場合は、手動での解除が必要になることがあります。

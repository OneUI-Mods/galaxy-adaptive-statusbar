# クラッシュ保護の誤作動を抑制

SystemUIやホームを続けて読み直したとき、終了理由を確認できないだけでクラッシュ保護が働くことがある問題を修正しました。自動配色やアニメーション追従をOFFにした後の終了も、その機能のクラッシュとして数えないようにしました。

確認できた異常終了が短時間に繰り返された場合や、フック処理でエラーが起きた場合の保護は引き続き有効です。停止理由の記録も改善しました。

対応環境はGalaxy SM-S948Q、Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHLです。libxposed API 102対応のVectorが必要です。

更新後はSystemUIとOne UIホームを読み直すか、ソフトリブートしてください。すでに保護で停止している場合は、アプリの「状態」で保護状態を確認し、保護を解除してから自動配色をONにしてください。更新だけで保護停止は解除されません。

実験版です。OSや他のモジュールが原因の終了を、このモジュールが修復することはできません。他の端末・OSビルドでは動作を保証していません。

設定アプリなどを開閉したあとに、時計やアイコンの色が一瞬戻ってちらつく問題を改善しました。

- システム側の標準色が更新されても、自動配色を保つようにしました。
- アニメーションから通常表示へ戻る際も、色のフェードと反転を抑える状態を引き継ぎます。
- 自動配色をOFFにすると、最新の標準色へ戻ります。文字ごと・アイコンごとの配色と、色のフェード時間設定は引き続き利用できます。

**対応環境**

Galaxy S26 Ultra（SM-S948Q）、Android 16 / One UI 8.5、ビルド `BP4A.251205.006.S948QOPS1AZHL` の縦画面が対象です。rootとVectorが必要です。アニメーション追従はOne UIホーム17.5.03.27に対応します。

**更新手順**

添付の `*-release.apk` をアンインストールせず上書きしてください。設定は引き継がれます。Vectorの対象を **SystemUIとOne UIホームの両方** に設定し、両方を再読み込みするか端末を再起動してください。再読み込みでロック画面に戻る場合があります。

**既知の制限**

追従は縦画面・単一ウィンドウ・現在のアプリ1枚が対象です。すべての履歴カード、分割画面、横画面、DeX、3Dカード効果、Home Upの全設定は対応未確認です。iOSとの完全な動作一致や長時間の安定性は保証していません。指定外の端末・OSビルド・One UIホームのバージョンでは利用できません。

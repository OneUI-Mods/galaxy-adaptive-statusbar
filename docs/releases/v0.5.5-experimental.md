# Galaxy Adaptive Bar 0.5.5 実験版

端末起動時とアプリ更新後に保存された設定を読み込み、自動配色とアニメーション追従を復帰させます。通常起動・ソフトリブート後とも、最初のロック解除後に動作します。設定アプリを毎回開く必要はありません。

自動復帰自体はrootコマンドや常駐サービスを使いません。OFFにしていた設定と、作動中のクラッシュ保護は維持します。起動中に設定の準備が間に合わなくても、配色処理の異常として数えずに待機します。

設定画面の宣伝調の見出しを削除しました。

## 対応環境と更新

Galaxy S26 Ultra（SM-S948Q）、Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHL、One UIホーム17.5.03.27が対象です。配色・アニメーション機能には従来どおりrootとVectorが必要です。

既存版を削除せず、署名済みrelease APKを上書きしてください。Vectorの対象をSystemUIとOne UIホームに設定し、ソフトリブートすると自動復帰の改善が反映されます。設定は引き継ぎます。

## 制限

実験版です。配色は消灯・ロック中に停止します。アニメーション追従は縦画面・単一ウィンドウ・現在のアプリ1枚が対象です。すべての履歴カード、分割画面、横画面、DeX、Home Upの全設定は対応未確認です。

# Android 17でのバッテリー配色と開閉表示を改善

Android 17でバッテリーが白いままになる問題と、アプリの開閉中にバッテリー表示が欠ける問題を修正しました。カプセルと残量文字が背景に合わせて切り替わり、設定したフェード時間で変化します。個別設定・全体設定をOFFにすると純正の配色へ戻ります。

連続クラッシュを起こしていたバッテリーの処理を取り除きました。クラッシュ保護は引き続き有効です。録画中の赤い表示を含む背景付きアイコンの開閉追従と、設定画面の改善も含まれます。

Android 17 / One UI 9はGalaxy S26 Ultra（SM-S948Q、BZI9）の実験対応です。Android 16 / One UI 8の対応も維持しています。未対応の端末やファームウェアではフックを有効にしません。現在は縦画面での利用が中心です。

署名済みrelease APKを上書きインストールしてください。フックを利用中の場合はSystemUIの再読み込みが必要です。再読み込み後にロック画面へ戻る場合があります。アプリデータの削除は不要です。

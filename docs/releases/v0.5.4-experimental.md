# Galaxy Adaptive Bar 0.5.4 実験版

設定画面を「配色」「調整」「状態」「情報」の4つのタブに整理しました。タブを移動しても設定値とスクロール位置を保持し、表示言語やテーマの変更後も開いていたタブへ戻ります。

ライセンスは検索できるライブラリ一覧に変更しました。名前・バージョン・ライセンスの種類を確認してから、各項目の本文と著作権表示を個別に読めます。

## 対応環境と更新

Galaxy S26 Ultra（SM-S948Q）、Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHL、One UIホーム17.5.03.27が対象です。rootとVectorが必要です。

既存版をアンインストールせず、署名済みrelease APKを上書きしてください。設定は引き継がれます。0.5.3からの更新は設定画面の変更が中心です。新規導入や古い版から更新する場合は、Vectorの対象をSystemUIとOne UIホームの両方に設定し、ソフトリブートしてください。

## 制限

実験版です。アニメーション追従は縦画面・単一ウィンドウ・現在のアプリ1枚が対象です。すべての履歴カード、分割画面、横画面、DeX、3Dカード効果、Home Upの全設定は対応未確認です。iOSと完全に同じ動作にはなりません。

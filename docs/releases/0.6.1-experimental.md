# ロック解除後の復帰を安定化

起動後の最初のロック解除時に、ステータスバーやホーム画面が再読み込みされることがある問題を修正しました。

libxposed API 102対応のVectorが必要です。対象はGalaxy SM-S948Q / Android 16 / One UI 8.5、ビルドBP4A.251205.006.S948QOPS1AZHLです。

更新後はSystemUI・One UIホームへの適用を確認し、ソフトリブートしてください。クラッシュ保護が停止を表示している場合は、アプリ内で保護状態を確認してから再試行してください。

実験版のため、他の端末やOSビルドでは動作を保証していません。

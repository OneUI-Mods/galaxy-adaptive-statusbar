# Galaxy Adaptive Bar 0.6.19 実験版

アプリや履歴の切り替え中に背景が一時的に透明になると、自動配色がエラー扱いになって停止する問題を修正しました。背景の準備ができるまで標準色で待機し、有効な背景を取得すると自動で配色を再開します。

背景を一部だけ取得できたフレームの色が、次の配色判断へ残る動作も改善しました。

対応するGalaxy S26 Ultra（SM-S948Q）のAndroid 16 / One UI 8.5とAndroid 17 / One UI 9が対象です。API 102対応Vectorが必要です。既存の署名済みrelease APKへ上書きし、SystemUIを一度再読み込みしてください。設定は引き継ぎます。

実験版です。画面消灯・ロック中は処理を停止します。保護画面では標準色へ戻り、横画面やHome Upのすべての構成は対応未確認です。

# カメラ・マイク表示の登場を滑らかに

カメラ・マイクの使用表示が出るとき、右側のアイコンと表示全体が一緒に滑らかに移動し、フェードするようにしました。使用中に残る小さな緑の点も少し大きくし、隣のアイコンとの間に余白を作ります。

「調整」→「カメラ・マイクの使用表示」でONにすると、次の使用表示から適用します。初期設定はOFFです。OFFにすると純正の大きさと位置へ戻ります。表示が混み合っているときや対象外の画面では、純正の表示を使います。

Android 17 / One UI 9、Galaxy S26 Ultra（SM-S948Q、BZI9）の縦画面・左から右へ読むレイアウト向けの実験機能です。Android 16用の既存機能は維持しています。rootとAPI 102対応Vectorが必要です。

署名済みrelease APKを上書きし、SystemUIを再読み込みしてください。ロック画面へ戻る場合があります。設定の削除は不要です。

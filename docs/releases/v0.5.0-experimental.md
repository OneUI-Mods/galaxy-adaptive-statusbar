アプリの開閉や履歴への移行に合わせて、ステータスバーがウィンドウへ追従する実験機能を追加しました。移動中も時計の文字ごと・アイコンごとの自動配色を継続します。

- 消えるバーと現れるバーのフェード、履歴から戻るときの明るさの変化を調整しました。
- 履歴へ移る途中に固定位置のバーが一瞬戻る問題を修正しました。
- 履歴への移行時に自動配色が停止することがある問題と、タッチ操作への警告が表示される問題を修正しました。
- One UIホームにもクラッシュ保護を追加しました。連続した異常終了や処理エラーで停止し、利用者が保護を解除するまで停止状態を維持します。

**対応環境**

Galaxy S26 Ultra（SM-S948Q）、Android 16 / One UI 8.5、ビルド `BP4A.251205.006.S948QOPS1AZHL` の縦画面が対象です。rootとVectorが必要です。アニメーション追従はOne UIホーム17.5.03.27に対応し、Home Upで調整されたアニメーションでも動作を確認しています。

**導入・更新**

添付の `*-release.apk` をインストールしてください。既存版はアンインストールせず上書きすると設定を保持できます。Vectorで対象を **SystemUIとOne UIホームの両方** に設定し、両方を再読み込みするか端末を再起動してください。再読み込みでロック画面に戻る場合があります。

アプリで自動配色をONにし、「アプリの開閉に追従」をONにしてください。追従が不要な場合は、この項目をOFFにすると通常位置での自動配色を使えます。色のフェード時間設定は引き続き利用できます。

**既知の制限**

追従は単一ウィンドウ・現在のアプリ1枚が対象です。すべての履歴カード、分割画面、横画面、DeX、3Dカード効果、Home Upの全設定は対応未確認です。iOSとの完全な動作一致や長時間の安定性は保証していません。指定外の端末・OSビルド・One UIホームのバージョンでは利用できません。

実験版です。[導入手順と対応範囲](https://github.com/ryuya0124/galaxy-adaptive-statusbar#readme)を確認してからご利用ください。配布APKは署名済みreleaseビルドです。ソースZIPとSHA-256一覧も添付しています。

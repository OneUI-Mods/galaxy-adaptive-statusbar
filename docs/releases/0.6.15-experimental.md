# カメラ・マイク表示に合わせて右側のアイコンを移動

「調整」タブに「カメラ・マイクの使用表示」を追加しました。ONにすると、カメラ・マイクの使用表示が出るとき、右側の通信・バッテリー表示を滑らかに左へ移して場所を空けます。純正の使用表示とタップ操作を使います。

初期設定はOFFで、次の使用表示から適用します。OFFでは純正の位置と表示へ戻ります。表示が混み合っている場合や対象外の画面では、純正の挙動へ戻します。

Android 17 / One UI 9、Galaxy S26 Ultra（SM-S948Q、BZI9）の縦画面・左から右へ読むレイアウト向けの実験機能です。Android 16用の既存機能は維持しています。rootとAPI 102対応Vectorが必要です。

署名済みrelease APKを上書きし、SystemUIを再読み込みしてください。ロック画面へ戻る場合があります。設定の削除は不要です。

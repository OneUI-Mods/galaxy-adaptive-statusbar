# 使用表示から緑の点への動きを改善

カメラ・マイクの使用表示が小さな点へ変わるとき、右側のアイコンが急に位置を変えず、滑らかに戻るようにしました。点の拡大と余白、表示全体が滑り込む登場アニメーションも利用できます。

「調整」→「カメラ・マイクの使用表示」に「空きが少ないときは純正表示へ戻す」を追加しました。初期設定はONです。OFFでは空きが少なくても移動を続けるため、時計や通知が多いと表示が重なることがあります。

Android 17 / One UI 9、Galaxy S26 Ultra（SM-S948Q、BZI9）の縦画面・左から右へ読むレイアウト向けの実験機能です。Android 16用の既存機能は維持しています。rootとAPI 102対応Vectorが必要です。

署名済みrelease APKを上書きし、SystemUIを再読み込みしてください。ロック画面へ戻る場合があります。設定の削除は不要です。

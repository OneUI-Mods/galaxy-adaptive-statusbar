# 通信速度の配色と行間調整

Android 17 / One UI 9の通信速度表示に自動配色を追加しました。数値と単位が背景に合わせて切り替わり、数値の更新中も色を維持します。

「調整」タブの「通信速度の表示」から、数値と単位の行間をプレビュー付きで変更できます。「標準の行間に戻す」で元に戻せます。「通信・状態アイコン」または自動配色全体をOFFにした場合も、色と行間を純正へ戻します。

Android 17はGalaxy S26 Ultra（SM-S948Q、BZI9）の実験対応です。Android 16 / One UI 8の対応は維持しています。未対応の端末・ファームウェアではフックを有効にしません。現在は縦画面での利用が中心です。

署名済みrelease APKを上書きインストールし、フックを利用中の場合はSystemUIを再読み込みしてください。再読み込み後はロック画面へ戻る場合があります。アプリデータの削除は不要です。

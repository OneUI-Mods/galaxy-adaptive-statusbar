# Android 17向けSDK更新と通信速度の行間調整

Android 17のSDKへ更新しました。Android 16 / One UI 8の対応を維持しています。

「調整」タブの「通信速度の表示」で、数値と単位の行間をプレビュー付きで変更できます。調整範囲は標準〜+10dpで、標準へ戻すボタンも用意しました。Android 17 / One UI 9の通信速度表示に対応し、通信・状態アイコンまたは自動配色をOFFにすると純正へ戻ります。

Android 17はGalaxy S26 Ultra（SM-S948Q、BZI9）の実験対応です。未対応の端末・ファームウェアではフックを有効にしません。現在は縦画面での利用が中心です。

署名済みrelease APKを上書きインストールし、SystemUIを再読み込みしてください。再読み込み後はロック画面へ戻る場合があります。アプリデータの削除は不要です。
